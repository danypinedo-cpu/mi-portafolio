# Guia del Laboratorio 03

En este trabajo practicamos como usar ramas y subir cambios a GitHub.

## Programas que use

- **Git** para guardar los cambios
- **GitHub** para subir el proyecto
- *Visual Studio Code* como editor

### Pasos que segui

1. Clonar el proyecto
2. Crear mi rama
3. Subir mis cambios

## Comandos usados

Para ver mis ramas uso `git branch`.

```bash
git checkout -b mi-rama
git add .
git commit -m "Mi avance"
git push origin mi-rama
```

| Comando | Que hace |
|---------|----------|
| git branch | Muestra las ramas |
| git checkout | Cambia de rama |
| git pull | Baja los cambios |
